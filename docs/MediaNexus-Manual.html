影枢 用户手册

影视全行业素材同步与质检工作台 —— 素材同步 + 视频质检，一个工作台搞定。

MediaNexus 把两件麻烦事合在一起：一边用项目名智能匹配把本地项目和 NAS 素材智能关联、一键直达；一边对视频做批量质量检查（黑场 / 黑边 / 静音 / 一致性 / 多版本对比），并导出 Excel 报告。两个子系统共享同一份用户配置，互不干扰。

一、核心能力

  • 素材智能关联：项目名归一化 + 模糊匹配，自动关联本地项目与 NAS 素材；三栏同屏预览，一键直达。
  • 视频质量检查：黑场 / 黑边 / 静音 / 一致性检测 + 多版本对比，批量自动跑，区间精准标注。
  • 统一配置：同步与质检共享同一份用户配置（位于 %APPDATA%\MediaNexus\config.json），质检预设不漂移。
  • 后台不打断：索引 / 匹配 / 列举 / 复制全在后台线程，UI 永不阻塞；NAS 断连自动重试 3 次。
  • 报告导出：质检结果一键导出 Excel，明细清晰，便于交付与归档。

二、适用场景

  • 影视全流程：把本地项目与 NAS 原始素材快速对齐，告别手动翻找。
  • 素材管理：海量 NAS 素材按项目名自动归类到本地项目，支持忽略垃圾目录（OLD / 备份 / temp）。
  • 成片质检交付：自动扫黑场 / 黑边 / 静音，输出可验收报告。
  • 多版本比对：对比不同版本同名视频的基础参数差异（分辨率 / 帧率 / 编码等）。

四、建议阅读顺序（快速上手）

跟着做一遍，约 5 分钟上手

  1. 设置项目：填本地根目录、NAS 根目录、匹配阈值
  2. 扫描并缓存 NAS：首次建立索引（可暂停 / 继续）
  3. 确认 / 排除匹配结果：把候选绑定到项目或让位
  4. 从 NAS 拖拽素材到本地：后台复制，进度可见
  5. 打开 影枢 QC 做视频质检：右键文件即可发起
  6. 导出 Excel 质检报告：交付与归档

设置与扫描

打开 设置（⚙ 设置 / Ctrl+S）：

  • 本地总项目根目录：如 D:\Projects，其下每个子文件夹视为一个项目。
  • NAS 素材根目录（可多个）：UNC（\\server\share）或映射盘符（Z:\）。
  • 模糊匹配阈值：默认 80。误匹配多就调高（85~90），漏匹配多就调低（70~75）。
  • 忽略关键词：索引时跳过含这些词的目录（如 OLD / 备份 / temp）。

点「保存」后，点 🗄 扫描并缓存 NAS 建立索引（首次较慢，可暂停 / 继续；之后秒开）。

匹配算法与调优

策略优先级（由高到低）：

  • 完全匹配（100）：归一化后名称完全相同。
  • 包含匹配（≥88）：一方名称被另一方包含，如 龙王归来 ⊂ 龙王归来_重剪。
  • 编辑距离匹配：rapidfuzz 综合 ratio / partial_ratio / token_sort_ratio 取最高分。

归一化会自动剥离：版本号（_v1、(1)）、常见后缀（_剪辑版、_终版、_final）、尾随年份（_2024）、内外层括号（【样片】、(送审)）。

匹配确认与拖拽复制

  • 左栏：项目状态 ✅ 已匹配 / ⚠️ 待确认 / ❌ 未匹配；支持搜索与状态筛选。
  • 右栏：下拉切换候选（带相似度与策略标签）；✅ 确认为此项目 持久化绑定，🚫 排除此结果 降权重重新匹配。
  • 拖拽：从右栏 NAS 文件拖入中栏本地项目，自动后台复制，底部显示进度与失败数。

视频质检（影枢 QC）

在主窗口的本地 / NAS 文件上 右键 → 打开 QC 检测（自动载入并开始检测），或右键 → 多版本对比。质检窗口以独立非模态窗口运行，标题为 「影枢 QC」。

检测项

黑场 黑边 静音 一致性校验 多版本对比

  • 黑场：平均像素值低于阈值的连续帧（默认 ≥1s 计为黑场）。
  • 黑边：基于亮度剖面「悬崖梯度」识别人工黑边（左 / 右 / 上 / 下），支持极细黑边。
  • 静音：音频 RMS 能量低于阈值，按持续时长分级（忽略 / 警告 / 错误）。
  • 一致性：多文件间基础参数（编码 / 分辨率 / 帧率等）的一致性。
  • 多版本对比：对比多个版本文件夹内同名视频的基础参数差异。

检测预设

质检参数以「预设」管理，可保存多个（如默认 / 暗场专用 / 严格模式）并切换。预设统一存放在主配置的 qc_presets 键中，在主程序与 QC 窗口之间完全一致、不漂移。

常用默认阈值：黑帧 mean_pixel_threshold=3、黑边 cliff_gradient_min=25、静音 rms_threshold=0.005。

导出报告

检测完成后可导出 Excel 报告（openpyxl 生成），包含每个文件的明细结果（黑场 / 黑边 / 静音区间、一致性结论等），便于交付与归档。

常见问题

若 QC 窗口打开时报 OpenCV / openpyxl 导入错误，说明未安装质检依赖，请运行 pip install -r requirements.txt。
  • UNC 路径连不上？ 确认网络可达、有访问凭据（资源管理器先手动访问一次并勾选“记住我的凭据”）；右栏会自动重试 3 次并允许手动重试。
  • NAS 断了会卡 UI 吗？ 不会。目录读取和索引都在后台线程执行，UI 始终可操作。
  • 中文路径乱码？ 全程 UTF-8，配置存于 %APPDATA%，无乱码。
  • 万级文件卡顿？ 文件列表采用虚拟滚动 + 懒加载，只渲染可见行。
  • 换电脑后配置还在吗？ 配置在 %APPDATA%\MediaNexus\config.json，随用户账户；换机需重新扫描索引。
